# Tienda de Cartas Pokémon

App móvil hecha con React Native + Expo para Programación para Dispositivos Móviles II (UNIAJC, S841A, Grupo 4).

## Qué hace
- Catálogo de 1000 cartas en cuatro vistas: Original, Optimizada, Adaptativa y Sensores.
- Favoritas múltiples con imagen, guardadas en AsyncStorage.
- Carta 3D que se inclina con el acelerómetro (real o simulado), con calibración.
- Asistente de IA local que responde nombre, precio o descripción de la carta seleccionada.

## Archivos principales
- App.js: pantallas y lógica.
- AsistenteIA.jsx y modeloIA.js: asistente de IA local.

## Cómo ejecutarlo
npm install
npx expo start
(pulsa w para abrir la versión web)
